# Signal bot (Pocket Option, ручная торговля)

Бот присылает в Telegram готовые сигналы: пара, CALL/PUT, экспирация. Входишь руками в течение минуты.

## Стратегии (время Дубая, одинаковое зимой и летом)

| Окно | Стратегия | ТФ | Экспирация | Бэктест (2023-01 — 2026-10, mid bid/ask, вход через 1 мин) |
|---|---|---|---|---|
| 05:00–06:00 | Утро: против пробоя уровня, H1-структура в сторону пробоя | 5m | 15 мин | подбор 55,1% (2579), проверка 55,9% (1505), ~89 сделок/мес |
| 14:00–15:00 | День: против MSS после снятия ликвидности, свеча смещения ≥ 1 ATR | 5m | 5 мин | подбор 55,7% (584), проверка 60,3% (320), ~20 сделок/мес |

Безубыток: выплата 85% → 54,05%, 80% → 55,6%.

Логика 1:1 с бэктестом (`kernels.py` — тот же код). Проверено: на всей истории бот выдаёт те же 4107 + 913 сигналов, что бэктест; на усечённой 16-дневной истории — 150 из 150; прогон самого живого цикла main.py на 30 случайных днях с подменой OANDA историческими котировками — 127 из 127 сигналов совпали.

## Котировки
OANDA v20 API, mid M1. Нужен бесплатный демо-счёт OANDA → в личном кабинете «Manage API Access» → сгенерировать токен.
Котировки Pocket Option отличаются от OANDA — результат WIN/LOSS бот считает по OANDA. Сверяй со своими сделками.

## Secrets (Replit → Secrets)
- `OANDA_TOKEN` — токен OANDA
- `OANDA_ENV` — `practice` (демо-счёт) или `live`
- `TELEGRAM_BOT_TOKEN` — токен бота от @BotFather
- `TELEGRAM_CHAT_ID` — id чата/канала (бот должен быть в нём админом для канала)

Необязательные:
- `PAIRS` — пары через запятую, по умолчанию все 10: `eurusd,gbpusd,usdjpy,audusd,usdcad,usdchf,nzdusd,eurjpy,gbpjpy,xauusd`
- `STRATEGIES` — `MORNING,DAY` (можно оставить одну)

## Запуск
```
pip install -r requirements.txt
python main.py --check   # проверка: связь с OANDA и Telegram + сигналы последних 5 дней на истории
python main.py           # живой режим
```

## Что присылает
- сигнал сразу после закрытия 5-минутной свечи;
- результат WIN/LOSS после экспирации (цена входа = закрытие минуты входа, как в бэктесте);
- итог окна через 2 минуты после его конца.
Все сигналы и результаты пишутся в `data/signals.csv`.

## Важно
Бот должен работать постоянно (как минимум в 04:30–06:05 и 13:30–15:10 по Дубаю). Бесплатный Replit засыпает, когда вкладка закрыта — для постоянной работы нужен Reserved VM / Background Worker deployment или любой VPS.
