# Signal bot (Pocket Option, ручная торговля)

Бот присылает в Telegram готовые сигналы: пара, CALL/PUT, экспирация. Входишь руками в течение минуты.

## Стратегия (одна)

| id | Пара | Окно | Что | ТФ | Экспирация |
|---|---|---|---|---|---|
| A1 | USD/JPY | 08:00–09:00 Нью-Йорк = 17:00–18:00 Дубай зимой, 16:00–17:00 летом | выход Аллигатора из спячки по тренду H1 | 1m | 60 мин |

Логика: Аллигатор (13/8/5 по медианной цене, сдвиги 8/5/3) «спал» — расстояние между крайними линиями меньше 0,5 ATR14 на каждой из 10 прошлых свечей. Свеча 1m закрывается за пастью: выше всех трёх линий — CALL, ниже — PUT, и только если пробой в сторону тренда H1 (закрытие последнего часа выше/ниже EMA50 часовых закрытий). Торгуем ПО пробою. Только первый сигнал за день. Вход руками в течение минуты после закрытия свечи.

Бэктест (Dukascopy mid, вход через 1 мин после закрытия свечи), первый сигнал дня, 360 дней 2020–2026: винрейт 61,4%.
По годам: 2020 58,7% · 2021 61,0% · 2022 58,8% · 2023 57,4% · 2024 66,0% · 2025 60,9% · 2026 68,1%. Около 4–5 сигналов в месяц.
Найдено перебором 6,3 млн комбинаций Аллигатора с фильтрами; отбор на 2020-01…2025-06, проверка на 2025-07…2026-10.

Безубыток: выплата 85% → 54,05%, 80% → 55,6%.

Проверено: бот на всей истории даёт ровно те же 361 сигнал, что бэктест; на усечённой 35-дневной истории (как в живом режиме) — 60 из 60 сигналов совпали, поминутный прогон 15 дней — 0 расхождений.
Старые стратегии S1, T1–T8 удалены. Secret `BOT_STRATEGIES` со старыми id игнорируется.

## Котировки
Бесплатный график-фид Dukascopy (пакет `dukascopy-python`), без регистрации и токенов. Это тот же источник, что в бэктесте: M1, mid = (bid + ask) / 2, только минуты с тиками.
Котировки Pocket Option могут отличаться — результат WIN/LOSS бот считает по Dukascopy. Сверяй со своими сделками.

## Secrets (Replit → Secrets)
- `TELEGRAM_BOT_TOKEN` — токен бота от @BotFather
- `TELEGRAM_CHAT_ID` — id чата/канала (для канала бот должен быть админом)

Необязательные:
- `PAIRS`, `BOT_STRATEGIES` — больше не нужны: бот сам грузит только USD/JPY и включает A1. Старые значения игнорируются.

## Запуск
```
pip install -r requirements.txt
python main.py --chat-id # показать id чатов, где бота запустили (/start) или куда добавили админом
python main.py --check   # проверка: фид Dukascopy и Telegram + сигналы последних 5 дней на истории
python main.py           # живой режим
```

## Что присылает
- сигнал сразу после закрытия 1-минутной свечи (не больше одного в день);
- результат WIN/LOSS после экспирации с разницей в пунктах (+ в пользу сделки, − против; пункт: 0.0001, для JPY-пар 0.01, для золота 0.1);
- DAILY REPORT — в 19:30 по Дубаю, после экспирации последнего сигнала, Пн–Пт;
- WEEKLY REPORT — по субботам в 15:00 (неделя Вс–Сб);
- MONTHLY REPORT — 1-го числа в 06:00 (прошлый месяц).
  В каждом: итог и статистика по каждой стратегии (сделок, WIN/LOSS, винрейт, пункты — валюты и золото отдельно), в недельном — по дням, в месячном — по неделям, по парам, и полный список сделок: время, пара, направление, экспирация, цена входа → цена экспирации, пункты.
  Если бот был выключен в момент отчёта, отчёт придёт позже (в пределах 20 ч). Отправленные отчёты помнит data/reports_sent.json.
Все сигналы и результаты пишутся в `data/signals.csv`.

## Важно
Бот сам поднимает маленький HTTP-сервер на порту из переменной PORT (по умолчанию 8080): GET / отдаёт статус (время последней свечи по каждой паре, включённые стратегии, сделки в ожидании результата). Поэтому его можно запускать как web/API-артефакт проекта Replit — отдельный проект не нужен. Деплой должен быть Reserved VM (не Autoscale: тот засыпает без запросов).
Бот должен работать постоянно. Бесплатный Replit засыпает, когда вкладка закрыта — для постоянной работы нужен Reserved VM / Background Worker deployment или любой VPS.
