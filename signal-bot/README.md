# Signal bot (Pocket Option, ручная торговля)

Бот присылает в Telegram готовые сигналы: пара, CALL/PUT, экспирация. Входишь руками в течение минуты.

## Стратегии (время Дубая, одинаковое зимой и летом)

| Окно | Стратегия | ТФ | Экспирация | Бэктест (2023-01 — 2026-10, mid bid/ask, вход через 1 мин) |
|---|---|---|---|---|
| 06:00–07:00 | Утро: против пробоя уровня при низкой волатильности (ATR14 < 0,75 от среднего за 20 дней) | 15m | 10 мин | подбор 58,9% (830), проверка 58,9% (433), ~27 сделок/мес |
| 14:00–15:00 | День: против MSS после снятия ликвидности, свеча смещения ≥ 1 ATR | 5m | 5 мин | подбор 55,7% (584), проверка 60,3% (320), ~20 сделок/мес |

Безубыток: выплата 85% → 54,05%, 80% → 55,6%.

Логика 1:1 с бэктестом (`kernels.py` — тот же код). Проверено:
- на всей истории бот выдаёт те же 1276 утренних и 913 дневных сигналов, что бэктест;
- на усечённой истории 30 и 35 дней (как в живом режиме) — 150 из 150;
- полный рабочий цикл main.py (сигналы, результаты, отчёты) на 10 случайных днях с подменой фида историческими котировками — 30 из 30 сигналов и 30 из 30 результатов WIN/LOSS совпали с бэктестом.

## Котировки
Бесплатный график-фид Dukascopy (пакет `dukascopy-python`), без регистрации и токенов. Это тот же источник, что в бэктесте: M1, mid = (bid + ask) / 2, только минуты с тиками.
Котировки Pocket Option могут отличаться — результат WIN/LOSS бот считает по Dukascopy. Сверяй со своими сделками.

## Secrets (Replit → Secrets)
- `TELEGRAM_BOT_TOKEN` — токен бота от @BotFather
- `TELEGRAM_CHAT_ID` — id чата/канала (для канала бот должен быть админом)

Необязательные:
- `PAIRS` — пары через запятую, по умолчанию все 10: `eurusd,gbpusd,usdjpy,audusd,usdcad,usdchf,nzdusd,eurjpy,gbpjpy,xauusd`
- `STRATEGIES` — по умолчанию только `MORNING` (утро 06–07). Дневную можно включить: `MORNING,DAY`

## Запуск
```
pip install -r requirements.txt
python main.py --chat-id # показать id чатов, где бота запустили (/start) или куда добавили админом
python main.py --check   # проверка: фид Dukascopy и Telegram + сигналы последних 5 дней на истории
python main.py           # живой режим
```

## Что присылает
- сигнал сразу после закрытия 5-минутной свечи;
- результат WIN/LOSS после экспирации с разницей в пунктах (+ в пользу сделки, − против; пункт: 0.0001, для JPY-пар 0.01, для золота 0.1);
- отчёт сессии: утро — в 07:30, день — в 15:30 (сделок, WIN/LOSS/TIE, винрейт, список всех сделок с пунктами).
Все сигналы и результаты пишутся в `data/signals.csv`.

## Важно
Бот должен работать постоянно (как минимум 05:30–07:35 и 13:30–15:35 по Дубаю). Бесплатный Replit засыпает, когда вкладка закрыта — для постоянной работы нужен Reserved VM / Background Worker deployment или любой VPS.
